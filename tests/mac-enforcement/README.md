# Bounded remote enforcement probe

This operator entry is only for the reviewed `mobile.build` remote workspace route on one fresh private Revyl VM. It is not a generic local/paired-Mac launcher. The parent stages a new single-use nonce, exact version-2 launch proof, source/configuration seal and reviewed authority, then independently retains the actual returned build/operation IDs. No future ID, previous boot or caller exclusivity boolean is accepted as evidence.

The source archive must contain the real native source, simulator-provisioner sources, this entry, `probe-config.json` and `launch-proof/{source-manifest,launch-plan,context,authority}.json`. The sealed configuration supplies the actual run/nonce, source revisions, fixture identifier and configuration version. The manifest must hash every source/configuration input, including this entry. Native compilation uses a separate private copy so generated plists cannot change the sealed original inputs.

The actual reviewed tool command invokes `python3 -E -s tests/mac-enforcement/enforcement-entry.py --launch-nonce <actual nonce> --source-manifest-sha256 <actual raw hash>` with an explicit clean environment. It builds an unsigned real app only as an evidence carrier, observes established controller sockets from actual ancestors, records the actual boot/source/nonce chain, and invokes the bounded enforcement-only/restoration probe exactly once. It creates no simulator and executes no native tests. Native/backend build-record paths are explicitly unused in this enforcement-only mode, not fabricated build evidence.

Controlled stdout heartbeats exercise the real existing runner control connection; they are not external application traffic or a network bypass. Only the independently observed controller tuples are eligible for preservation. Missing sockets, unsupported PF/kernel/broker behavior, unproven restoration or any admission mismatch fails the job. A timeout waits only for the independent watchdog's cleanup record; it never force-disables PF, flushes global state or broadens rules.

On success, `out/CalledItMessages.app/QAEnforcementProbeEvidence` contains the actual owned records. This is a private unsigned artifact carrier, not an RC, native UI/provider/signing/distribution proof or full-V0 verdict. On failure, inspect the retained structured tool logs and stop/replan; do not retry with invented provenance or broader exceptions.

`inspect-control.py --nonce <fresh UUIDv4>` is a separate read-only diagnostic after the actual TCP-controller preflight found no eligible socket. It uses the real macOS SDK/libproc to inspect only current ancestor socket families, states and nonsecret VM socket endpoints, records executable hashes/current boot and optionally reads the kernel's vsock table. It does not call the provisioner or PF, create a simulator, send a packet, change a policy or approve a different control profile. `QAControlInspectionEvidence` holds observations only; a later isolation design must be reviewed against the actual result.
