This is the V0 integration branch of Called It: a native iPhone app with a Messages extension in `native-imessage/` (Swift, XcodeGen) and a Convex backend in `convex/`. There is no Expo, React Native or web app on this branch; `web/index.html` is one static page with no scripts.

## Commands

```bash
npm ci --ignore-scripts      # install
npm run typecheck            # tsc --noEmit
npm run lint                 # eslint, then scripts/check-static.mjs
npm run test:backend         # backend tests, in-memory, no network
npm run test:local-backend   # local Convex backend on loopback
```

Run typecheck and lint before declaring any task done.

## Rules

- Never hard-code a Convex deployment address. Read it from configuration and fail when it is unset; `scripts/check-static.mjs` enforces this outside `tests/`.
- Tests use in-memory or local backends with synthetic data only. Never deploy from a task.
- V0 is iPhone and iMessage only and reads no chats, photos or contacts. Do not add copy that says otherwise.
- The Xcode project is generated by XcodeGen from `native-imessage/project.yml` and is not committed; edit `project.yml`.
